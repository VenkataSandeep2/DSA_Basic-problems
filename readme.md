# DSA ZERO - HERO LEVEL

A beginner-friendly, step-by-step Java DSA learning path for Eclipse, LeetCode practice, placements, and technical interviews.

## Daily workflow (60 minutes)
- 10 minutes — concept
- 25 minutes — solve the problem
- 15 minutes — dry-run, debug, and test
- 10 minutes — revise and record progress

## Course rules
- Try the exercise before requesting a complete solution.
- Learn brute force before optimization.
- Use one hint at a time.
- Ask for a smaller example if a concept is difficult.
- Only mark a day complete when the learner confirms completion or an authorized integration verifies it.
- Keep attempts, mistakes, and hints separate from completion status.
