# Java DSA Basic-to-Hero Roadmap

This 30-day sprint is an initial path, not a guarantee of mastery in 30 days. Adapt pace to verified progress.

| Day | Topic | Goal |
|---:|---|---|
| 1 | Two Sum — Brute Force | Understand array indices and check pairs with two nested loops. |
| 2 | Time and Space Complexity | Estimate how runtime and extra memory grow as the input grows. |
| 3 | Running Sum of 1D Array | Practice a left-to-right traversal while maintaining a running total. |
| 4 | Concatenation of Array | Create and fill a result array using correct indices. |
| 5 | Array Traversal and Edge Cases | Handle array length, empty inputs, and boundary positions safely. |
| 6 | Prefix Sums — Find Pivot Index | Track totals to compare the values on both sides of an index. |
| 7 | Weekly Review — Arrays and Brute Force | Explain previous approaches and retry one problem without notes. |
| 8 | HashMap Fundamentals | Understand keys, values, insertion, lookup, and membership checks. |
| 9 | Two Sum — HashMap Optimization | Compare complement lookup with the brute-force pair search. |
| 10 | Contains Duplicate | Use a set to remember values already seen. |
| 11 | HashSet and Membership Checks | Practice add and contains operations and uniqueness. |
| 12 | Valid Anagram | Compare character frequencies and string lengths. |
| 13 | Arrays and Hashing Review | Choose an appropriate data structure and justify the complexity. |
| 14 | Two Pointers | Move two indices using a clear rule or invariant. |
| 15 | Valid Palindrome | Compare characters from both ends and move inward. |
| 16 | Move Zeroes | Move zeroes while preserving the relative order of other elements. |
| 17 | Sliding Window | Maintain a moving contiguous range without recomputing everything. |
| 18 | Best Time to Buy and Sell Stock | Track the minimum price so far and the best profit found. |
| 19 | Sorting Fundamentals | Compare basic sorting methods and reason about their trade-offs. |
| 20 | Binary Search | Search a sorted array by shrinking the low/high interval. |
| 21 | Linked List Fundamentals | Understand nodes, references, traversal, and null termination. |
| 22 | Stack — Valid Parentheses | Use last-in, first-out behavior to match delimiters. |
| 23 | Queue and Deque | Understand FIFO behavior and operations at both ends. |
| 24 | Recursion Fundamentals | Identify a base case and make progress toward it on each call. |
| 25 | Binary Tree Traversal | Recognize preorder, inorder, and postorder traversal orders. |
| 26 | BST and Heap Introduction | Compare binary-search-tree ordering with heap priority ordering. |
| 27 | Graph BFS and DFS | Traverse graph vertices while tracking visited nodes. |
| 28 | Greedy Algorithms | Assess when a locally optimal choice can solve the full problem. |
| 29 | Dynamic Programming Introduction | Identify states, repeated subproblems, and stored results. |
| 30 | Mock Interview and Revision | Explain the approach, correctness, complexity, edge cases, and trade-offs. |

## Adaptation rule
If a concept is unclear, pause the sequence, use smaller examples, and practice again before increasing difficulty. HashMap-based Two Sum follows the brute-force lesson.
