# Day 1 — Two Sum Test Cases

Run each test after completing your implementation.

| Case | Input | Target | Expected indices |
|---|---|---:|---|
| Basic | `[3,4,6,8]` | 10 | `[1,2]` |
| Duplicate values | `[3,3]` | 6 | `[0,1]` |
| Negative value | `[-2,7,11]` | 5 | `[0,1]` |
| First and last | `[1,8,4,2]` | 3 | `[0,3]` |
| No pair (generalized variant) | `[1,2,3]` | 20 | Define and document behavior |

LeetCode guarantees one valid answer for the standard Two Sum problem. If you build a generalized variant, define and test the no-answer behavior.
